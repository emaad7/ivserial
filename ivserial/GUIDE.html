1. What the package does

ivserial tests whether a time series is a sequence of independent and identically distributed (i.i.d.) values. The test is rank based and exact: under independence its P-value is valid for every sample size and every continuous distribution, with no model, bandwidth or tuning parameter to choose. It reports

  • the P-value of the proposed combined test C and of its two components: the block statistic Q, which sees dependence among several consecutive values, including dependence that is invisible in every pair, and the portmanteau P2, which looks at pairs at lags 1 and 2;
  • V-hat, the strength of the dependence on a scale from 0 to 1 (the serial Cramér coefficient, which for pairs is Cramér’s V), and Gamma-hat, the efficiency of the test;
  • the patterns of consecutive values that occur unusually often or rarely, which show what kind of dependence is present;
  • sample size and power calculations, and the explicit null distribution of Q.

2. Two ways to use it

Without programming: the window (GUI)
Open a CSV or Excel file, pick a column, press Run test. Sample-size planning and the null distribution are in their own tabs.
With code: Python or the command line
serial_test(x) in a Python script or notebook, or ivserial data.csv in a terminal. Suited to many series and to reproducible work.

Both use the same functions and give the same results: everything that can be done in code can also be done in the window, and the other way round. The table lists the correspondence.

3. Installation

Step 1: Python (once)

  • Windows: download Python 3 from https://www.python.org/downloads/. In the first screen of the installer tick "Add python.exe to PATH", then Install Now. Check in Command Prompt: python --version.
  • macOS: install from python.org; in Terminal use python3 and pip3 instead of python and pip.
  • Linux: Python is usually installed; for the window you may need sudo apt install python3-tk.

Step 2: the package, like any other Python module

Open a terminal (Command Prompt on Windows) and run one of

pip install ivserial                                     # from the Python Package Index (recommended)
pip install git+https://github.com/emaad7/ivserial      # latest version from GitHub (needs Git)

The package page on the Python Package Index is pypi.org/project/ivserial; the source code, examples and this guide are at github.com/emaad7/ivserial. To update to a newer version later, run pip install --upgrade ivserial.

Without internet access, download the wheel file ivserial-1.0.1-py3-none-any.whl (from the Releases page on GitHub or the Download files page on PyPI), open a terminal in the folder where you saved it, and run pip install ivserial-1.0.1-py3-none-any.whl.

The required libraries numpy and scipy are installed automatically. For Excel files also run pip install pandas openpyxl (or pip install "ivserial[excel]"). If pip is not found, use python -m pip install ....

After installation you have

  • the Python module: import ivserial;
  • the command ivserial in any terminal;
  • the command ivserial-gui, which opens the window (also python -m ivserial).

Check: ivserial --version prints ivserial 1.0.1. This guide is installed with the package: ivserial guide opens it, as does the User guide button in the window.

Without installing

On GitHub press Code → Download ZIP and unzip the file, run pip install numpy scipy once, and double-click run_gui_windows.bat (Windows), run_gui_mac_linux.command (macOS, Linux) or ivserial_gui.pyw.

4. Preparing your data

  • A CSV, TXT or Excel (.xlsx) file, or any numeric array in Python.
  • One series per column, rows in time order (oldest first). A first row with names is optional; non-numeric columns such as dates are ignored; missing values are removed.
  • At least 20 observations; several hundred give the most informative results.
  • Prices or returns? The test is applied to the values you give it. For prices and other trending series use the log returns (or differences): a trending series is never i.i.d., and the test would only detect the trend.

The folder examples contains exchange_rates.csv, the 20 daily exchange rates analysed in the paper (prices; use the log-return transform).

5. The window (GUI)

Start it with ivserial-gui, python -m ivserial, or by double-clicking as described above. It has three tabs.

Test tab

  1. Open data file... and choose your file.
  2. Choose the series (column), or tick test all columns to screen every column at once.
  3. Choose the transform: none, differences, or log returns (prices).
  4. Press Run test. Save report... writes the output as text (.txt) or as structured results (.json).

The options can be left at their defaults: B = 9999 random permutations, block length m and classes d chosen automatically, level 0.05, portmanteau with lags 1 and 2. Keep the seed fixed to make the P-values reproducible.

6. Python

import numpy as np
from ivserial import serial_test, required_sample_size, approximate_power

x = np.loadtxt("returns.txt")            # any 1-d array, in time order
res = serial_test(x, seed=1)             # B = 9999 permutations by default
print(res)                               # full report, as in the window

res.p_C, res.reject                      # P-value of C and decision at level 0.05
res.p_Q, res.p_P2, res.p_Q_asymptotic    # components and asymptotic P-value
res.cramer_v                             # strength of dependence, between 0 and 1
res.gamma_hat, res.tau_hat               # efficiency and its standard deviation
res.cells[:5]                            # most over- and under-represented patterns
res.to_dict()                            # all results, e.g. for a pandas DataFrame

serial_test(prices, transform="logdiff", label="WTI")    # prices -> log returns
serial_test(x, m=3, d=4, lags=3, B=99999, alpha=0.01)    # options

Reading a data file as in the window:

from ivserial import read_table
cols = read_table("examples/exchange_rates.csv")       # {column name: array}
for name, v in cols.items():
    r = serial_test(v, transform="logdiff", seed=1, label=name)
    print(name, round(r.p_C, 4), round(r.cramer_v, 3))

ItemMeaning
CThe test to use. A P-value below the level (e.g. 0.05) rejects serial independence.
Q, P2Blocks of m consecutive values, and pairs at lags 1 and 2. C combines them exactly.
permutation / asymptoticPermutation P-values are exact; asymptotic ones use the explicit limits and are accurate for n ≥ 350.
V-hatStrength of dependence, between 0 and 1 (serial Cramér coefficient): 0 means that blocks of m consecutive classes are independent, 1 that the class of any one value determines its whole block. For m = 2 it is Cramér’s V of consecutive classes. Compare values at the same (m, d).
Gamma-hatEfficiency: the normalized information variance, the approximate Bahadur slope of the test; Gamma = (dm−1 − 1)·V². It drives the sample-size calculation.
PatternsEach value is assigned to one of d classes by its rank (1 = lowest, d = highest). Residual = (observed − expected)/√expected; |residual| > 3 is notable.

Example (Chinese yuan, from the paper). The pattern 3-3-3 occurs 41 times against 7.5 expected (residual 12.2): runs of near-zero changes around the official reference rate. The patterns 1-5-5, 1-1-5 and 5-5-5, made of large moves of either sign, reflect volatility clustering.

A rejection means that the values are not i.i.d. The patterns indicate the kind of dependence, not a particular model.

9. Sample size and power

The normalized information variance Gamma is the efficiency of the test (its approximate Bahadur slope), so it converts directly into a sample size (Corollary 4.8 of the paper):

power ≈ Φ( (K·Gamma + μ0 − qα) / √(K·tau² + V0) ),   K = n − m + 1,

where μ0, V0 and qα are the mean, variance and upper α point of Lm,d. serial_test estimates both Gamma and tau from the data, so a pilot sample or a comparable series gives a realistic plan. With tau = 0 the formula is accurate for weak dependence and otherwise optimistic. For example, for an ARCH(1) process at (m, d) = (3, 4), with Gamma = 0.13 and tau = 1.13 estimated from data, the predicted power at n = 350 is 0.85, against 0.82 in simulations; with tau = 0 it would be 0.98.

10. Residuals of fitted models

The test can be applied to residuals, for example standardized GARCH residuals, to check whether dependence remains. The P-values are then only approximately exact. When the model is estimated efficiently (maximum likelihood with the correct innovation distribution), they remain valid and are slightly conservative (Theorem 4.11 of the paper). After Gaussian quasi-maximum likelihood with non-normal innovations they can be misleading, especially for squared residuals; then use a model-based bootstrap: simulate from the fitted model, re-estimate, and recompute the statistic (Section 4.5 of the paper).

12. Reference and citation

Default resolution: (m, d) = (3, 3) for n < 300, (3, ⌊(n−300)/400⌋+4) for 300 ≤ n < 1500, and m = ⌊log n/(2 log 3)⌋, d = 3 beyond; portmanteau classes 3, 4 or 5. Ties are broken at random, which keeps the test exact. P-value = (1 + #{permuted statistics ≥ observed})/(B + 1). Computing time: about 1 second for n = 1000 with B = 9999, and about 15 seconds for n = 100,000 with B = 999.
